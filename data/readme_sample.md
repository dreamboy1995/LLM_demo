# AI Agent 开发框架

## 什么是 AI Agent？
AI Agent 是一种能自主理解、规划、执行复杂任务的智能体。
它通常包含四个核心组件：大语言模型（LLM）、规划模块、记忆模块和工具使用模块。

## LangChain
LangChain 是目前最流行的 AI 应用开发框架，支持 Python 和 JavaScript。
它提供了 Chain、Agent、Tool、Memory 等抽象，极大地简化了大模型应用的开发。

## 向量数据库
向量数据库将文本转换为向量（Embedding），通过计算向量相似度实现语义搜索。
常用的向量数据库包括 Chroma、Milvus、Pinecone 等。
